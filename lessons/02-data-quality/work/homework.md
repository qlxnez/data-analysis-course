## H1 Правила функции

Функция clean_export(source) принимает исходную таблицу export. Она возвращает три результата: clean — подготовленные данные, quarantine — строки с ошибками, audit — журнал очистки. Функция проверяет повторные записи, конфликты по source_row, пробелы в данных, правильность числовых значений и обязательные условия: известный номер организации, допустимый исход, положительная сумма кредита и территория 11001. Доход income может быть неизвестным.

## H3 Проверка года и виды проблем

Для проверки создаётся копия wrong_year, в которой год первой записи изменяется на "2022". Затем выполняется проверка year_ok на равенство всех значений "2023". Результат проверки — False, значит, нарушение обнаружено. Исходная таблица export при этом остаётся без изменений.
- Исходный пропуск: значение дохода отсутствует. Оно остаётся неизвестным и не заменяется нулём.
- Ошибка преобразования: например, вместо числа указано "abc". Такое значение нельзя преобразовать в число, поэтому оно отмечается как ошибка.
- Необычно большая сумма: например, 999999. Это числовое значение успешно преобразуется, но выглядит подозрительно. Его нужно дополнительно проверить, а не автоматически считать ошибкой преобразования.
